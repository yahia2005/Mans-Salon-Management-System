# 💈 Man's Salon Management System

[![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)](https://www.java.com/)
[![MySQL](https://img.shields.io/badge/MySQL-00000F?style=for-the-badge&logo=mysql&logoColor=white)](https://www.mysql.com/)
[![Swing](https://img.shields.io/badge/GUI-Java_Swing-blue?style=for-the-badge)](#)

A modern, full-featured Desktop Application designed for barbershop management, financial reporting, worker attendance, and service tracking.

---

## 🔥 Key Features

- **📊 Live Profit & Loss Dashboard:** Instant calculation of daily revenue, total expenses, and net profit with threshold alerts.
- **💈 Order & Service Management:** Fast processing for barbershop operations and active service tracking.
- **👥 Attendance System:** Attendance recording per worker using dynamic GUI check-boxes and database persistence (`ON DUPLICATE KEY UPDATE`).
- **💸 Expense Tracking:** Daily operational expense logs.
- **🎨 Modern UI/UX:** Clean, sidebar-navigated interface using `CardLayout` and Flat Look & Feel.

---

## 🏗️ Architecture & Tech Stack

- **Architecture Pattern:** Data Access Object (DAO) Pattern separating GUI, Business Logic, and Database queries.
- **Language:** Java 8+
- **GUI Framework:** Java Swing & AWT (`CardLayout`, `JTable`, Custom Adapters)
- **Database:** MySQL Server
- **JDBC Driver:** MySQL Connector/J
